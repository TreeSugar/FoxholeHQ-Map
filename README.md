# FoxholeHQ Tilemap

A 256 x 256 Tilemap created by **TreeSugar** for **FoxholeHQ's** Interactive Map to be used in the Airborne Update. [FoxholeHQ Map](https://foxholehq.com/map)

## Note
Foxhole imagery such as the map hexagons are created by and owned by **Siege Camp** the creators of Foxhole. The map contents were stitched together to create a 10987 x 7143 image and then sliced into 256 x 256 images.
